# Voedingsdagboek

Een gratis voedingsdagboek voor je telefoon. Geen advertenties, geen account,
geen tracking. Je gegevens blijven op je eigen toestel.

**Status:** fase 0 — de plannen staan in de map `docs/`. Er is nog geen app.

- Wat de app doet en niet doet: [docs/VISIE.md](docs/VISIE.md)
- Functies per fase: [docs/EISEN.md](docs/EISEN.md)
- Hoe het gebouwd is: [docs/ARCHITECTUUR.md](docs/ARCHITECTUUR.md)
- Privacy: [docs/PRIVACY.md](docs/PRIVACY.md)

Installeren, bijwerken en back-ups maken wordt hier uitgelegd zodra de app
er is (fase 1).
